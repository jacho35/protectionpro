Lightning risk assessment

Step 1 of 4 — tell us about the structure
IEC 62305-2:2010Risk to life, R1
Steps
What this assessment decides
  • It estimates R1, the yearly risk that lightning causes loss of human life in or at this structure, through shock, fire, or (for hospitals, hotels, schools and explosion risks) failure of internal systems.
  • It compares R1 with the tolerable risk RT = 1 × 10⁻⁵ per year (IEC 62305-2, Table 7).
  • If R1 is too high, it finds the lowest lightning protection system (LPS) class and surge protection (SPD) level that bring it below RT.
You’ll need: the building’s size, the site’s lightning ground flash density, how many people use it and for how long, and the power and telecom lines that enter it.
Scope: one structure, assessed as a single zone. Not assessed: loss of public service (R2), cultural heritage (R3) or economic loss (R4).

ProtectionPro — Help & Documentation

Welcome to ProtectionPro

ProtectionPro is a browser-based power systems engineering tool for building single-line diagrams (SLDs) and performing electrical analysis — a lightweight, web-based alternative to ETAP.

Building a Single-Line Diagram

  1. Add components — Drag components from the left sidebar palette onto the canvas. Use the search box to filter components. Categories include sources, distribution, protection, instruments, loads, DC systems, and other.
  2. Connect components — Click a connection port (small circle) on one component and drag to a port on another to draw a wire. Alternatively, press W for Wire mode.
  3. Configure properties — Click a component to select it. Edit its electrical properties in the right-hand properties panel (voltage, impedance, ratings, etc.). Sequence impedances (positive, negative, zero) can be entered for sources, cables, and motors.
  4. Run analysis — Open the Analyse menu on the single-line toolbar: every analysis (short circuit, load flow, arc flash, cable sizing and more) is grouped there by discipline. Press Ctrl K to find any command by name.

Templates

Use Project → Templates to start from a pre-built network: substation, industrial plant, residential distribution, or generator installation. Templates provide a fully wired and configured starting point.

Canvas Navigation

  • Pan — Middle-click drag or hold Space + left-click drag
  • Zoom — Mouse scroll wheel, or use Fit / 1:1 buttons in the toolbar
  • Select — Click a component, or drag a selection box around multiple components
  • Multi-select — Hold Shift and click to add/remove from selection
  • Dark mode — Toggle via the Dark button in the top-right toolbar

Multi-Page Diagrams

Use the page tab bar below the canvas to add, rename, and switch between diagram sheets. Double-click a tab to rename it. To move devices to another sheet, cut them (Ctrl+X), switch sheets, and paste (Ctrl+V). Use off-page connectors to link electrical connections across pages — connectors with the same label are electrically joined.

Bus Resizing

Hover over a bus to reveal resize handles on each end. Drag the handles to make the bus wider or narrower. Connection ports are automatically added as the bus grows — one top/bottom pair per 40px of width. Edge ports (left/right) are available for bus tie breaker connections.

Component Grouping

Select multiple components and press Ctrl+G to group them. Groups can be selected together and moved as a unit. Press Ctrl+Shift+G to ungroup.

Wire Routing

Choose between orthogonal (right-angle), diagonal, or spline wire routing via View → Wire Routing. Double-click a wire to add bend points for custom routing. Directional flow arrows on wires show power flow direction after running load flow analysis.

Saving & Exporting

Use Ctrl+S to save your project. Projects can be saved to the server or exported in multiple formats via the Reports menu:

  • JSON — Full project data (re-importable)
  • SVG / PNG — Diagram image export
  • CSV — Analysis results as spreadsheet
  • PDF — Full report with title block, legend, and border
  • Settings Schedule — Protection device settings CSV
  • Arc Flash Labels — Printable warning labels (PDF)
  • Detailed Calculations — Step-by-step formulas and intermediate values (PDF)

Scenarios

Use Scenarios → Manage Scenarios to save named network configuration snapshots. Compare scenarios side-by-side via Scenarios → Compare Scenarios to evaluate different operating conditions or design alternatives.

Mobile Support

On a phone, ProtectionPro has its own layout. The header switches workspace and holds undo, redo and save. The bottom tabs are Parts (tap to place), Diagram, Studies (every analysis, searchable, with its options before you run it), Results (per-bus results, worst first, with Locate) and More (project, edit, quantities, scenarios, output, diagram layers and settings). Selecting a component shows a card with Edit, Rotate, Duplicate, Copy and Delete; Edit opens the full-screen properties editor, which steps through components with ‹ ›. Pinch to zoom, drag to pan, and use the layers button to switch sheets.

Verification & Validation

All sixteen analysis engines are cross-checked against published standards, textbook worked examples, or exact first-principles / hand calculations. Each reference is rebuilt as a reproducible project and solved two ways that must agree — the backend engine (authoritative) and the real app driven headlessly — with a pass tolerance of ±2 %.

DXF drawings (Site plan & Floor plans)

  • ⬆ Import Plan → pick a .dxf. A floor can hold several (architectural + services, survey + services). Layers, blocks with their attributes and every curve type (arcs, bulged polylines, splines, ellipses, hatches, dimensions) are read. DWG isn't supported — save as DXF from your CAD package.
  • Scale: a DXF with units lands at true scale; on an uncalibrated floor it sets the scale. A unitless DXF asks what one drawing unit is. DXFs drawn on the same grid line up automatically.
  • Background Plans row: show/hide, opacity, ◫ manager, ✥ move, ⤢ 2-point align (keeps true scale), ✕ remove (undoable).
  • ◫ Layers: show/hide and recolour each CAD layer; map a layer to a route type, trench, rooms/areas or (Site plan) erf boundaries — erven are numbered from the text inside each boundary.
  • ◫ Blocks: each block with a preview, count and attribute tags. Map a block to a plan device and each attribute to a field (name/erf no., circuit, board, load, cable). Convert places editable devices at each block's position and rotation; converted items are hidden from the DXF, the conversion is one undo step, and the mappings are remembered for the next issue of the drawing.
  • Snap DXF snaps to line ends, midpoints, vertices, circle/arc centres and block insertion points.
  • A DXF exported from ProtectionPro (⤓ DXF) re-imports as editable devices, routes (type, cable, end points), trenches, crossings and rooms, in either plan type.
